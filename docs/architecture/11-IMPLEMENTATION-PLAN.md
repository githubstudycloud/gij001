### 4.2 监控指标

```yaml
核心监控指标:
  基础设施:
    - K8s 节点 CPU/内存/磁盘
    - Pod 运行状态
    - 网络流量

  中间件:
    - MySQL QPS/连接数/慢查询
    - Redis 命中率/内存/连接数
    - RocketMQ 堆积/TPS

  应用:
    - 请求 QPS/RT/错误率
    - JVM 内存/GC/线程
    - 业务指标

  SLO:
    - 可用性 > 99.9%
    - P99 延迟 < 500ms
    - 错误率 < 0.1%
```
