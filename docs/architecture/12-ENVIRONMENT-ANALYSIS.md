### 2.2 中间件问题

| 组件 | 现状 | 问题 | 建议 |
|------|------|------|------|
| RabbitMQ 3.6 | 单机 | 版本老旧，单点故障，不支持延迟队列 | 升级或迁移到 RocketMQ |
| Kafka (内/外) | 分散 | 内外分离，管理复杂 | 统一治理 |
| RocketMQ (内部) | 未使用 | 资源浪费 | 利用起来做内部消息 |
| MongoDB | 2集群 | 可能冗余 | 评估合并 |
| GitLab | 配置中心 | 非专业配置中心，无动态刷新 | 增加 Nacos |

## 四、5台测试服务器部署规划

```yaml
# 服务器角色分配
server-1: (16C32G)
  role: k8s-master + etcd
  services:
    - k8s control plane
    - Nacos (node1)
    - Grafana

server-2: (16C32G)
  role: k8s-worker (middleware)
  services:
    - Nacos (node2)
    - RocketMQ (NameServer + Broker-Master)
    - Redis (复用已有)

server-3: (16C32G)
  role: k8s-worker (middleware)
  services:
    - Nacos (node3)
    - RocketMQ (NameServer + Broker-Slave)
    - Elasticsearch (node1)

server-4: (16C32G)
  role: k8s-worker (observability)
  services:
    - VictoriaMetrics
    - Loki
    - Tempo
    - Elasticsearch (node2)

server-5: (16C32G)
  role: k8s-worker (business)
  services:
    - XXL-JOB
    - 业务服务
    - Elasticsearch (node3)
    - MinIO (或使用集团S3)
```
