## 一、现有模型调研结论

### 1.1 是否有现成的日程分类模型？

**结论：没有现成可用的日程分类模型**

原因：
- 日程分类是小众需求
- 缺少公开的日程分类数据集
- 现有模型主要集中在情感分析、新闻分类等通用任务

## 二、快速收集/生成训练数据

### 2.1 数据需求量

| 数据量 | 效果预期 | 推荐场景 |
|--------|---------|---------|
| 200-500条 | 基本可用 | 快速验证 |

| 1000-3000条 | 效果较好 | 生产环境 |
| 3000条以上 | 效果优秀 | 高精度需求 |

### 2.2 数据格式

```json
{"text": "明天下午3点开会", "label": 1}
{"text": "今天天气真好", "label": 0}
{"text": "记得周五交报告", "label": 1}
{"text": "这个功能很实用", "label": 0}
```

- `label: 1` = 包含日程
- `label: 0` = 不包含日程

### 2.3 方法一：LLM批量生成（最快）

使用GPT/Claude/通义千问批量生成训练数据：

**生成正样本的提示词：**
```
请生成50条包含日程信息的中文句子。

要求：
1. 句子要自然、口语化
2. 包含各种时间表达：具体日期、相对时间（明天、下周）、时间点
3. 包含各种事件类型：会议、约会、提醒、任务、出差等
4. 长度在10-50字之间
5. 风格多样：工作、生活、社交等场景

输出格式（每行一条）：
明天上午10点和客户开会
...
```

**生成负样本的提示词：**
```
请生成50条不包含日程信息的中文句子。

要求：
1. 句子要自然、口语化
2. 可以包含时间词但不构成日程（如"昨天很累"、"以前经常去"）
3. 包含各种话题：闲聊、评论、描述、提问等
4. 避免任何未来计划或安排
5. 长度在10-50字之间

输出格式（每行一条）：
今天天气真不错
...
```

**批量生成脚本：**
```python
import openai
import json

def generate_samples(prompt: str, count: int = 50) -> list:
    response = openai.chat.completions.create(
        model="gpt-4o-mini",
        messages=[{"role": "user", "content": prompt}],
        temperature=0.9  # 增加多样性
    )
    lines = response.choices[0].message.content.strip().split('\n')
    return [line.strip() for line in lines if line.strip()]

# 生成正负样本
positive_samples = generate_samples(POSITIVE_PROMPT, 200)
negative_samples = generate_samples(NEGATIVE_PROMPT, 200)

# 构建数据集
dataset = []
for text in positive_samples:
    dataset.append({"text": text, "label": 1})
for text in negative_samples:
    dataset.append({"text": text, "label": 0})

# 保存
with open("train_data.json", "w", encoding="utf-8") as f:
    for item in dataset:
        f.write(json.dumps(item, ensure_ascii=False) + "\n")
```

**成本估算：**
- 生成1000条数据约需 5-10次API调用
- GPT-4o-mini成本：约 $0.1-0.2
- 通义千问成本：约 ¥0.5-1

### 2.4 方法二：模板扩充

定义模板，自动组合生成：

```python
import random
import json

# 时间模板
TIMES = [
    "明天", "后天", "下周一", "下周五", "这周六", "月底",
    "3点", "上午10点", "下午2点半", "晚上8点",
    "明天上午", "后天下午", "下周三晚上"
]

# 事件模板
EVENTS = [
    "开会", "见客户", "交报告", "做汇报", "面试",
    "出差", "培训", "聚餐", "看医生", "取快递",
    "打电话给{person}", "和{person}吃饭", "陪{person}逛街"
]

# 地点模板
LOCATIONS = [
    "", "在会议室", "在星巴克", "在公司", "在医院",
    "去北京", "去上海", "在3楼"
]

# 人名
PERSONS = ["老王", "小李", "张总", "客户", "老板", "同事"]

# 句式模板
PATTERNS = [
    "{time}{event}{location}",
    "记得{time}{event}",
    "{time}要{event}",
    "别忘了{time}{event}",
    "{time}{location}{event}",
]

def generate_positive():
    pattern = random.choice(PATTERNS)
    time = random.choice(TIMES)
    event = random.choice(EVENTS)
    location = random.choice(LOCATIONS)
    person = random.choice(PERSONS)

    text = pattern.format(time=time, event=event, location=location)
    text = text.format(person=person) if "{person}" in text else text
    return text.strip()

# 负样本模板
NEGATIVE_TEMPLATES = [
    "今天天气{adj}",
    "这个{thing}真{adj}",
    "上次{event}很{adj}",
    "听说{person}{did}",
    "{person}说{thing}不错",
    "最近{feeling}",
]

# 生成数据集
dataset = []
for _ in range(500):
    dataset.append({"text": generate_positive(), "label": 1})
# ... 负样本类似

with open("train_data.json", "w", encoding="utf-8") as f:
    for item in dataset:
        f.write(json.dumps(item, ensure_ascii=False) + "\n")
```

### 3.2 完整微调代码

```python
import torch
from transformers import (
    AutoTokenizer,
    AutoModelForSequenceClassification,
    TrainingArguments,
    Trainer
)
from datasets import load_dataset
import numpy as np
from sklearn.metrics import accuracy_score, precision_recall_fscore_support

# ==================== 1. 加载数据 ====================
# 假设数据格式为 jsonl: {"text": "...", "label": 0/1}
dataset = load_dataset("json", data_files={
    "train": "train_data.json",
    "test": "test_data.json"
})

# ==================== 2. 加载模型和分词器 ====================
MODEL_NAME = "hfl/chinese-roberta-wwm-ext"

tokenizer = AutoTokenizer.from_pretrained(MODEL_NAME)
model = AutoModelForSequenceClassification.from_pretrained(
    MODEL_NAME,
    num_labels=2,  # 二分类
    id2label={0: "非日程", 1: "日程"},
    label2id={"非日程": 0, "日程": 1}
)

# ==================== 3. 数据预处理 ====================
def tokenize_function(examples):
    return tokenizer(
        examples["text"],
        padding="max_length",
        truncation=True,
        max_length=128
    )

tokenized_datasets = dataset.map(tokenize_function, batched=True)

# ==================== 4. 定义评估指标 ====================
def compute_metrics(eval_pred):
    logits, labels = eval_pred
    predictions = np.argmax(logits, axis=-1)

    accuracy = accuracy_score(labels, predictions)
    precision, recall, f1, _ = precision_recall_fscore_support(
        labels, predictions, average="binary"
    )

    return {
        "accuracy": accuracy,
        "precision": precision,
        "recall": recall,
        "f1": f1
    }

# ==================== 5. 训练参数 ====================
training_args = TrainingArguments(
    output_dir="./schedule_classifier",
    num_train_epochs=3,
    per_device_train_batch_size=16,
    per_device_eval_batch_size=16,
    warmup_steps=100,
    weight_decay=0.01,
    logging_dir="./logs",
    logging_steps=50,
    eval_strategy="epoch",
    save_strategy="epoch",
    load_best_model_at_end=True,
    metric_for_best_model="f1",
)

# ==================== 6. 创建Trainer并训练 ====================
trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=tokenized_datasets["train"],
    eval_dataset=tokenized_datasets["test"],
    compute_metrics=compute_metrics,
)

# 开始训练
trainer.train()

# ==================== 7. 保存模型 ====================
trainer.save_model("./schedule_classifier_final")
tokenizer.save_pretrained("./schedule_classifier_final")

print("训练完成！")
```

    num_labels=2

### 3.5 推理使用

```python
from transformers import AutoTokenizer, AutoModelForSequenceClassification
import torch

# 加载微调后的模型
model_path = "./schedule_classifier_final"
tokenizer = AutoTokenizer.from_pretrained(model_path)
model = AutoModelForSequenceClassification.from_pretrained(model_path)
model.eval()

def predict(text: str) -> dict:
    inputs = tokenizer(text, return_tensors="pt", truncation=True, max_length=128)

    with torch.no_grad():
        outputs = model(**inputs)
        probs = torch.softmax(outputs.logits, dim=-1)

    predicted_class = torch.argmax(probs, dim=-1).item()
    confidence = probs[0][predicted_class].item()

    return {
        "text": text,
        "has_schedule": bool(predicted_class),
        "confidence": round(confidence, 3),
        "label": "日程" if predicted_class else "非日程"
    }

# 测试
print(predict("明天下午3点开会"))
# {'text': '明天下午3点开会', 'has_schedule': True, 'confidence': 0.967, 'label': '日程'}

print(predict("今天天气不错"))
# {'text': '今天天气不错', 'has_schedule': False, 'confidence': 0.923, 'label': '非日程'}
```

## 五、常见问题

### Q1: 训练数据不平衡怎么办？
```python
# 方法1: 加权损失
from torch.nn import CrossEntropyLoss
weights = torch.tensor([1.0, 2.0])  # 日程类权重更高
loss_fn = CrossEntropyLoss(weight=weights)

# 方法2: 过采样
from imblearn.over_sampling import RandomOverSampler
```

### Q2: 效果不好怎么优化？
1. 增加训练数据（最有效）
2. 检查数据质量，剔除噪声
3. 添加更多边界case
4. 调整学习率（尝试1e-5到5e-5）
5. 增加训练轮数

### Q3: 模型太大怎么压缩？
```python
# 使用distilbert或小模型
model = AutoModelForSequenceClassification.from_pretrained(
    "hfl/chinese-roberta-wwm-ext-small"  # 小版本
)

# 或量化
model = torch.quantization.quantize_dynamic(
    model, {torch.nn.Linear}, dtype=torch.qint8
)
```
