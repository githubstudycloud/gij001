# 方案选择决策指南

本文档帮助您根据具体情况快速选择最适合的解决方案。

---

## 快速决策流程图

```
开始
  │
  ├─ 是否需要快速上线（< 1周）？
  │   ├─ 是 → 方案一：LLM直接调用
  │   └─ 否 ↓
  │
  ├─ 是否有数据隐私要求（不能用云API）？
  │   ├─ 是 → 是否有GPU资源？
  │   │       ├─ 是 → 方案二：LLM微调
  │   │       └─ 否 → 方案三：传统NLP
  │   └─ 否 ↓
  │
  ├─ 日均处理量是否超过10万条？
  │   ├─ 是 → 方案四：混合方案
  │   └─ 否 → 方案一：LLM直接调用
  │
结束
```

## 详细决策矩阵

### 根据核心需求选择

| 您的核心需求 | 推荐方案 | 理由 |
|-------------|---------|------|
| 最快上线 | 方案一 | 无需训练，即开即用 |
| 最高准确率 | 方案二 | 针对性优化 |
| 最低成本 | 方案三 | 无API费用 |
| 平衡各方面 | 方案四 | 兼顾效果与成本 |
| 完全离线 | 方案二/三 | 本地部署 |
| 处理量大 | 方案四 | 分层处理 |

### 根据资源条件选择

| 您拥有的资源 | 推荐方案 |
|-------------|---------|
| 仅有API预算 | 方案一 |
| 有少量标注数据 | 方案一+Few-shot |
| 有大量标注数据 | 方案二 |
| 有GPU服务器 | 方案二 |
| 有NLP工程师 | 方案三/四 |
| 资源都有 | 方案四 |

## 各方案启动清单

### 方案一：LLM直接调用

**准备工作（1-2天）**
- [ ] 注册API账号（OpenAI/通义千问/智谱）
- [ ] 获取API Key
- [ ] 选择提示词模板
- [ ] 编写调用代码
- [ ] 测试效果

**推荐技术栈**
```
API: 通义千问（国内）/ GPT-4o-mini（海外）
语言: Python
框架: LangChain（可选）
```

**预估成本**
- 开发：1-2人天
- 运行：约 ¥0.01-0.05/条（视模型而定）

---

### 方案二：LLM微调

**准备工作（3-4周）**
- [ ] 准备标注数据（至少500条）
- [ ] 选择基座模型（推荐Qwen2.5-7B）
- [ ] 准备GPU服务器（至少24GB显存）
- [ ] 搭建训练环境
- [ ] 执行微调训练
- [ ] 部署推理服务
- [ ] 测试与优化

**推荐技术栈**
```
基座模型: Qwen2.5-7B-Instruct
微调方法: LoRA/QLoRA
训练框架: transformers + peft
推理引擎: vLLM
部署: Docker + Kubernetes
```

**预估成本**
- 开发：10-15人天
- 数据标注：视数据量
- 硬件：约 ¥8000-15000/月（云GPU）

**准备工作（4-6周）**

- [ ] 准备训练数据

### 方案四：混合方案

**准备工作（2-3周）**
- [ ] 分析数据分布
- [ ] 定义分层规则
- [ ] 开发规则预处理层
- [ ] 选择轻量分类模型
- [ ] 集成LLM调用
- [ ] 实现路由逻辑
- [ ] 性能测试与调优

**推荐技术栈**


**预估成本**
- 开发：10-15人天
- 运行：约 ¥0.002-0.01/条

## 常见问题解答

### Q1: 我应该用国内还是国外的API？

**选择国内API（通义千问、智谱）如果**：
- 用户主要在国内
- 需要稳定的访问速度
- 对数据出境有顾虑

**选择国外API（OpenAI、Claude）如果**：
- 需要处理多语言
- 对模型能力要求极高
- 已有海外服务器

### Q2: 需要多少训练数据才能微调？

| 数据量 | 效果预期 |
|--------|---------|
| 100-500条 | 可以尝试，效果一般 |
| 500-2000条 | 基本可用 |
| 2000-5000条 | 效果较好 |
| 5000条以上 | 效果优秀 |

### Q3: 如何评估方案效果？

**关键指标**
1. **准确率**：整体分类正确率
2. **召回率**：日程信息的识别率（重要！漏掉日程比误判更糟）
3. **响应时间**：P95延迟
4. **成本**：单条处理成本

**建议基准**
- 准确率 > 90%
- 召回率 > 95%
- P95延迟 < 500ms（直接调用）< 100ms（本地部署）

### Q4: 方案之间可以迁移吗？

可以，推荐的迁移路径：

```
方案一（验证可行性）
    ↓ 收集数据
方案二（提升效果）或 方案四（优化成本）
    ↓ 规模增长
方案四（最终形态）
```
